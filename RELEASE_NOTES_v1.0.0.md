# LLM Behaviour Architecture v1.0.0

Initial public case-study version.

## What is included

- Long-context behaviour architecture
- Persistent versus task-local context model
- Instruction hierarchy and conflict handling
- Behavioural failure taxonomy
- Qualitative evaluation framework
- 18 sanitised/reconstructed evaluation cases
- Machine-readable test matrix
- Regression-oriented retesting method
- Limitations and epistemic boundaries
- Citation and copyright metadata

## Evaluation principle

> State observations as observations. State mechanisms as hypotheses unless independently evidenced. Treat successful interventions as evidence, not proof.

## Scope

This release is a professional portfolio artefact demonstrating the methodology used to reason about conversational AI behaviour.

It is not presented as production-scale benchmarking, deterministic model control, or direct interpretability of proprietary model internals.
