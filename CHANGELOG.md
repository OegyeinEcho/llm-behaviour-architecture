# Changelog

All notable changes to this portfolio case study are documented here.

The project uses semantic-style versioning for the public case-study artefact. Version numbers describe the state of the published framework and documentation, not an underlying model or software package.

## [1.0.0] - 2026-09-29

### Added

- Public LLM behaviour architecture case study
- Context-layer model separating task-local and persistent context
- Instruction hierarchy and conflict-resolution model
- Behavioural failure taxonomy
- Evaluation framework covering relevance, instruction adherence, intent alignment, context stability, uncertainty, user agency, and regression resistance
- 18-case qualitative evaluation matrix
- Machine-readable CSV test matrix
- Sanitised and reconstructed behavioural test cases
- Limitations and non-goals documenting epistemic boundaries
- Design-decisions document explaining the text-first approach
- Citation metadata via `CITATION.cff`
- Copyright and reuse notice
- System-map visual asset
- Portfolio-oriented README and repository navigation

### Evaluation scope

The v1.0.0 case study establishes the qualitative framework and evaluation discipline.

It does not yet include:

- repeated-run quantitative benchmarking
- automated test execution
- model/version comparison datasets
- statistical reliability estimates
- production telemetry
- automated regression scoring

Those are possible future extensions rather than implied capabilities of the current release.
